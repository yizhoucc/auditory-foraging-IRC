# Auditory Foraging with IRC

An implementation using IRC (Information-Rational Control) to solve an auditory foraging task. The agent uses a belief-based POMDP model with PPO for decision-making under uncertainty.

## Setup

```bash
# clone
git clone -b yc2 https://github.com/yizhoucc/auditory-foraging-IRC.git
cd auditory-foraging-IRC

# create venv
python3 -m venv venv
source venv/bin/activate   # linux/mac
# venv\Scripts\activate    # windows

# install deps
pip install torch numpy scipy matplotlib pyyaml stable-baselines3 'shimmy>=2.0' gym multiprocess seaborn pandas

# optional, for notifications and logging
pip install requests tensorboard wandb
```

## Project structure

```
auditoryforage/         task environment (AF_env.py defines the POMDP)
irc_gym/                wrapper around Stable Baselines 3
  irc/                  belief model, agent, manager
  jarvis/               config, archiving, utilities
notebooks/              training and plotting notebooks
yctest/                 experiment notebooks
ycstore/                trained model checkpoints (gitignored, generated by training)
ult.py                  shared utilities, plotting helpers, episode runner
```

## How it works

- `AF_env.py` defines the auditory foraging POMDP with continuous Gaussian observations. The agent chooses (lick, attention_level) at each step. Lower attention std = more precise observations but higher cost.
- `FuncBeliefModel` wraps the task into a belief MDP that PPO can train on.
- Training notebooks (`vary *.ipynb`, `varying *.ipynb`) train PPO agents under different parameter sweeps (reward, number of nodes, observation quality).
- Plot notebooks (`plot *.ipynb`) load trained models from `ycstore/` and generate figures.

## Running notebooks

Notebooks assume the working directory is the repo root. If using Jupyter:

```bash
source venv/bin/activate
jupyter notebook
```

**Training notebooks** (names starting with `vary` or `varying`):
- These train PPO agents and save checkpoints to `ycstore/`.
- They run independently. Some continue training from prior epochs — if starting fresh, change the epoch range to start from 0.
- GPU is optional; training is mostly CPU-bound (environment simulation). Each PPO model uses <20MB GPU memory.

**Plot notebooks** (names starting with `plot`):
- These load models from `ycstore/` and generate figures.
- You need to run the corresponding training notebook first.

## Running training without Jupyter

You can extract notebook cells into a standalone script. The key pattern:

```python
import sys, os
sys.path.insert(0, os.getcwd())
sys.path.append(os.path.join(os.getcwd(), 'irc_gym'))

from auditoryforage.AF_env import AuditoryForagingReward2 as AFR2
from irc_gym.irc.model import FuncBeliefModel
from stable_baselines3 import PPO
from ult import run_one_episode

task = AFR2(spec={'agent': {'lick_cost': 0, 'food_reward': None,
                            'attention_cost_coeff': -1.6,
                            'attention_cost_temp': 0.25,
                            'penalty_cost': -50, 'iti_cost': 0,
                            'time_in_game_reward': 0}})
task.food_reward_list = [10, 2500, 5000, 7500, 10000]
taskbelief = FuncBeliefModel(env=task, rng=1)

model = PPO('MlpPolicy', taskbelief, verbose=0, device='cuda')
model.learn(total_timesteps=100000)
model.save('ycstore/my_model')
```

## Environment classes

| Class | Description |
|---|---|
| `AuditoryForaging` | Base POMDP with continuous Gaussian observations |
| `AuditoryForagingReward2` | Same as base (reward index in belief is default) |
| `AFnorate` | Same as base (no time-division in reward is default) |
| `AF2p` | Varies observation quality (p1) across episodes |
| `AF2pp` | Varies p1 and p2 without varying reward |
| `AuditoryForagingEnergy` | Tracks cumulative attention energy usage |
| `AFVaryAttention` | Varies attention cost across episodes |
